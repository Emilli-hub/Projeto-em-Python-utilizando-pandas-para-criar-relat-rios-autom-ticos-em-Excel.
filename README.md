# Projeto em Python utilizando pandas para criar relatórios automáticos em Excel

## 📊 Sobre o projeto

Este projeto foi desenvolvido em Python utilizando a biblioteca pandas para criar tabelas, realizar cálculos automáticos e exportar arquivos Excel.

## 🚀 Tecnologias utilizadas

* Python
* pandas
* Excel
* VS Code

## 📌 Funcionalidades

* Criação de tabelas
* Cálculo automático de bônus e médias
* Exportação para Excel
* Manipulação de dados

## 💻 Objetivo

Praticar análise de dados e automação utilizando Python.
